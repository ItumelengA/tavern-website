# Tavern Website

A modern and responsive tavern website designed to showcase food, drinks, events, and the welcoming atmosphere of a local tavern. The site features a clean design, smooth navigation, and a mobile-friendly experience for visitors.

## Features

- Responsive design
- Modern user interface
- Food and drinks showcase
- Contact section
- Mobile-friendly layout
