A modern and responsive tavern website designed to showcase menu offerings, special events, and the unique atmosphere of the tavern. The website provides visitors with an engaging experience through elegant design, smooth navigation, and mobile-friendly layouts.

Features
* Responsive design for desktop and mobile devices
* Modern and attractive user interface
* Menu showcase section
* Featured drinks and food items
* Contact and location information
* Fast-loading static website hosted on GitHub Pages
